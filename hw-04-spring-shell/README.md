# Приложение для проведения опросов на Spring Shell

## Цель:
Использование Spring Shell, чтобы писать интерфейс приложения без Web.

## Результат:
Приложение на Spring Shell

## Описание:
В ресурсах хранятся вопросы и различные ответы к ним в виде CSV файла (5 вопросов).
Вопросы с выбором из нескольких вариантов ответа.

## Требования:
1. Подключить Spring Shell, используя spring-starter.
2. Написать набор команд, позволяющий проводить опрос.
3. Перенести тесты на @SpringBootTest. Компоненты и моки взять из тестового контекста, в остальном это должны быть юнит-теста. Учесть, что Spring Shell в тестах нужно отключить

## Новый функционал:
Выполняется на основе предыдущего домашнего задания (hw-03-spring-boot).

## Список команд Spring Shell:
help - вывод списка доступных команд  
s, start - Запуск приложения  
l, login - Авторизация  
t, test - Запуск теста (выполняется только после авторизации студента)  
r, result - Вывод результата тестирования (выполняется только после прохождения теста)
